# 실서비스 흐름 조사

조사일: 2026-09-30. 사용자 홈 화면 2장, 공식 도움말 본문 및 도움말의 등록 메뉴 이미지를 확인했다.
실서비스의 시작 버튼은 NAVER 로그인으로 이동했다. 로그인 이후 기능 화면은 직접 확인하지 못했다.
따라서 아래 '확인'은 도움말이 설명하는 기능을 뜻하며 현재 로그인된 화면을 전부 검증했다는 뜻은 아니다.

## 복약관리

| 단계 | 공식 자료에서 확인 | UI 설계 전에 남은 확인 |
| --- | --- | --- |
| 등록 진입 | 오른쪽 메뉴에서 약봉투 촬영, 영양제 검색, 처방/일반약 검색 선택. 도움말 이미지에서도 메뉴 확인 | 실제 데스크톱 웹 메뉴와 카드 구성 |
| 검색 등록 | 이름으로 약·영양제 검색; 결과가 없으면 이름 직접 등록 | 검색 결과 카드, 필수 입력값, 중복 처리 |
| 촬영 등록 | 카메라 촬영 후 사진 분석 | 인식 결과 수정·확정·실패 UI |
| 일정과 기록 | 시간 설정에 따른 알림, 사용자의 복용 여부 기록 | 요일·기간·횟수 설정, 과거 기록과 체크 취소 정책 |
| 상세 | 이름·성분·효능·주의사항 제공 | 정보 출처·표기 구조 |
| 알림 | 개별 약, 약카드, NAVER 앱 및 기기 알림 설정 필요. 예정 시간 전에 체크하면 알림 미발송 | Windows 자체 알림 구현·앱 종료 및 절전 정책 |
| 복용 종료 | 카드 선택 → 더보기 → 복용 종료. 알림과 체크 중지, 다시 시작하려면 새 등록 | 과거 기록 보존·종료 후 화면 구성 |

사진 업로드·OCR·실제 의약품 검색 API는 계약을 확인하지 않았다. 첫 구현에서는 직접 등록과 합성 검색 데이터를 사용한다.
촬영 버튼을 작동하지 않는 장식으로 넣지 않는다. 후속으로 구현할 때 실제 인식 기능과 시뮬레이션을 명시한다.

## 바디리포트

공식 소개는 날짜별 리포트, 주요 지표 카드(체중·골격근량·체지방률·체지방량), 근육·지방·수분 분석, 체중조절 목표, 대사·활력 정보를 설명한다.
날짜 이동 버튼·캘린더로 측정일을 선택하고 코너별 AI 요약을 선택하면 상세 해석 패널을 연다.
현재 코너별 AI 해석과 업데이트 예정인 종합 진단·맞춤 목표·미션을 구분한다. 실제 분석 API와 판정 기준은 미확인이다.

연동 흐름: 시작 → 개인정보·민감정보 제3자 제공 동의 → 인바디 계정 인증 → 측정 조회.
실제 동의·인증은 이번 조사에서 수행하지 않았다. 자체 앱은 실제 인바디 비밀번호를 요구하지 않고 연동 시뮬레이터를 사용한다.
도움말은 최초 조회가 최근 3년·최대 36건, 진입 시 갱신과 이후 10분 간격 재호출 및 수동 새로고침이라고 설명한다.
자동 해제 시 재연동 배너/팝업이 제공되며 재연동 전 기존 수집 데이터 조회가 가능하다고 설명한다.
수동 해제 후 보존·삭제 정책은 별도 개인정보처리방침 확인이 필요하다.

누락 값은 오류·0과 다르다. 기기에 따라 수분·체중조절 코너가 없거나 일부 값이 '-'로 표시된다.
데이터가 부족하면 AI 브리핑이 없을 수 있다. 흐름 AI 브리핑은 선택 기간 3건 미만일 때 미노출로 안내한다.
인바디에서 삭제한 데이터가 바디리포트에 자동 반영되지 않는다고 안내하며 날짜별 직접 삭제 기능은 업데이트 예정이다.
이 조건들은 실서비스 관찰 근거이고 자체 앱의 동기화 계약으로 자동 채택하지 않는다.

## 증상체크

공식 설명: 가장 불편한 증상 하나 입력 → 인기 증상 또는 부위별 선택 → 성별·연령 기본 정보 → 증상별 추가 질문 → 관련 질병·질병 정보·근처 의료기관 정보.
질문 내용, 분기 규칙, 판정 알고리즘, 결과 화면과 MY증상기록 상세는 미확인이다.
포트폴리오에서는 질문·답변·기록 탐색 UI를 만들 수 있다. 진단 로직이나 결과 문구를 임의로 실제 의료 정보처럼 생성하지 않는다.
'가족이 아플 때 사용'이라는 소개가 가족 계정 공유·권한 기능을 입증하지는 않는다.

## UI 근거와 다음 설계

- 사용자 홈: 두 열 카드, 기능 바로가기, 비연동·복약 없음·예약 없음 상태, 건강미션 예정 표시.
- 도움말 등록 이미지: 약 추가 메뉴에서 등록 방식 선택. 전체 화면의 최신 스타일 근거로 확대하지 않는다.
- 자체 Windows 설계: 고정 탐색, 날짜별 일정, 선택 항목 상세, 등록 단계와 오류 복구, 키보드·DPI 대응.
- 다음 시안 범위: 오늘의 건강 홈과 복약관리의 정상·빈 상태·직접 등록·저장 실패·복용 완료·종료 확인.
- 실제 내부 화면과 차이는 후속 자료가 확보되면 검토한다. 자료 미확보를 상세 UI 검증 완료로 처리하지 않는다.
